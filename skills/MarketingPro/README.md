# MarketingPro 品牌营销方法论 SKILL

## 简介

**MarketingPro** 是一个基于"品牌=复购"理论的品牌营销方法论智能体。它能够：

- 🔍 **品牌诊断** - 诊断增长方式、4P一致性、品牌资产、卖点体系
- 💬 **咨询问答** - 回答品牌营销相关问题，提供专业建议
- ✍️ **物料生成** - 生成slogan、文案、海报、详情页、视频脚本等
- 📋 **战略制定** - 制定完整的品牌战略文档

---

## 核心方法论

### 品牌 = 复购

> 品牌 = 企业给自己设计的一个方便客户奖惩的标签

- **唯一目的**：让消费者复购
- **终极效果**：取消销售（0成本的复购）
- **作用机制**：顾客奖惩

### 增长方式决定营销

| 增长类型 | 特征 | 4P应服务 |
|---------|------|---------|
| **产品驱动型** | 产品利润 > 顾客体验成本 | 产品优越性 |
| **推广驱动型** | 产品利润 < 顾客体验成本 | 购买冲动 |
| **渠道驱动型** | 顾客无法抹除信息差 | 渠道意愿 |

### 定力·定型·定投

- **战略定力**：不分散核心资源
- **资产定型**：持续储蓄同一个品牌资产
- **营销定投**：复制有效打法

## 使用指南

### 1. 品牌诊断
提供品牌信息，系统将：
- 判断增长类型
- 分析4P一致性
- 诊断品牌资产
- 输出诊断报告

### 2. 咨询问答
提出品牌营销问题，系统将：
- 分析问题类型
- 引用方法论框架
- 给出专业建议

### 3. 物料生成
提供产品信息，系统将生成：
- 品牌slogan
- 社交媒体文案
- 产品详情页
- 海报文案
- 新闻稿/品牌故事
- 视频脚本

### 4. 战略制定
提供企业信息，系统将输出：
- 完整的品牌战略文档
- 4P策略规划
- 执行计划
