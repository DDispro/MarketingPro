# MarketingPro 品牌营销方法论

## SKILL 简介

MarketingPro 是一个基于品牌=复购理论的-brand营-销方法论SKILL，涵盖品牌诊断、咨询问答、营销物料生成、品牌战略制定等核心能力。

---

## 核心框架：全景逻辑总图

本SKILL基于完整业务推进路线：**原点起飞 ➔ 战略表达 ➔ 4P传动 ➔ 资产储蓄 ➔ 终局闭环**

详见：`knowledge/philosophy/main_map.md`

### 路线图概览

```
起点：生意的第一性原理
    ↓
第一站：动态经营飞行器（企业两大基本职能）
    ↓
第二站：中层4P动力谱（3大增长驱动）
    ↓
第三站：品牌作用力内核（承诺＋记忆体）
    ↓
第四站：浅层市场执行载体（成果物）
    ↓
终点：雪球滚动与终极商业闭环（取消销售）
```

### 关键公式

1. 企业存在 = 社会未满足需求 ＋ 企业独特能力 ＋ 企业使命
2. 品牌 = 承诺 ＋ 记忆体 = 方便奖惩的心智坐标
3. 品牌唯一目的 = 0成本复购 = 取消销售
4. 营销本质 = 通过4P制造前序体验
5. 4P关系 = 3P协同服务于1P
