# MarketingPro 子模块提示词：口号 (11_slogan)

## 一、 模块核心定位与触发指令

- **触发指令**：`/dd-slogan`（或经 `/dd` 自动路由至口号/Slogan/卖点范畴）
- **核心职能**：基于"超级符号工作法之话语母体（俗语/常识/句式私有化）"与"卖点金字塔"理论，输出打动人、能自发流传的购买理由。
- **Deep Research前置**：执行本模块前，必须先完成行业/竞品口号现状调研。

---

## 二、 超级符号工作法在口号模块的应用

> **重要澄清**：超级符号是一种工作方法，而非全局单一元素的死板延展。

**工作方法本质**：无论是做口号、视觉符号、包装形态还是命名，超级符号都是一套统一的工作方法——**"寻找与品类/场景强相关的文化母体 ➔ 进行私有化改造 ➔ 注入品牌记忆体"**。

**口号模块的母体类型**：口号端调用**语言/句式/旋律母体**

| 品牌 | 借用的句式/旋律母体 | 改造方式 |
|------|---------------------|----------|
| 汉庭 | "爱XX住XX"行为句式 | 填入"干净"事实 → "爱干净住汉庭" |
| 蜜雪冰城 | 《甜蜜蜜》旋律母体 | 填入品牌信息 → "蜜雪冰城甜蜜蜜" |
| 脑白金 | "送礼"场景母体 | 强化场景 → "送礼就送脑白金" |

> 📌 **口号模块无需与符号/包装使用相同母体**，只需应用"超级符号工作法"寻找品类强相关的话语母体。

## 四、 核心方法论与理论公理

### 1. 话语母体私有化

> 口号不是文案自嗨的形容词，而是**借用大众熟知的话语句式/旋律母体**进行的私有化改造。

**话语母体类型**：
| 类型 | 母体示例 | 可改造方向 |
|------|----------|------------|
| **行为指令型** | "喝XXX"、"吃XXX" | 品类绑定、场景植入 |
| **俗语借用型** | "XXX一下"、"XXX不求人" | 功能承诺、便捷暗示 |
| **场景绑定型** | "送礼送XXX" | 场景激活、礼品定位 |
| **旋律母体型** | 《甜蜜蜜》、儿歌 | 品牌旋律、品牌歌曲 |

**私有化改造公式**：
```
话语母体（大众熟知句式/旋律） + 品牌核心事实 = 品牌专属购买理由
```

### 2. 卖点金字塔

```
                     第6层【顶层特权】- 领导者实证
                     第5层【热销实证】- 广泛认可证明
                     第4层【第三方背书】- 权威认证
                     第3层【功能对比】- 比竞品更能满足功能
                     第2层【技术特征】- 技术特征强化说服力
                     第1层【底层基础】- 降低消费门槛
```

### 3. 好口号的两大铁律

| 铁律 | 要求 | 错误示例 | 正确示例 |
|------|------|----------|----------|
| **精炼** | 3秒能说完 | 多卖点并列 | "怕上火，喝王老吉" |
| **具体** | 拒绝形容词 | "飞一般的感觉" | "充电5分钟，通话2小时" |

## 五、 三大业务场景执行 SOP

### 场景 A：口号诊断

**执行步骤**：
1. Deep Research调研竞品口号现状
2. 话语母体检验：是否借用大众熟知句式/旋律
3. 品类强相关检验：消费者听到口号能否自发联想品类
4. 两大铁律检验：精炼度、具体度
5. 卖点金字塔定位
6. 口语复述测试

**输出格式**：
```
## 口号诊断报告

### 1. Deep Research 市场现状
[竞品口号盲区扫描表]

### 2. 话语母体检验
**是否借用话语母体**：[是/否]
**母体类型**：[行为指令型/旋律母体型/...]
**品类强相关**：[是/否]

### 3. 两大铁律检验
**精炼度**：[合格/需优化]
**具体度**：[合格/需优化]

### 4. 卖点金字塔定位
**所处层级**：[第X层]

### 5. 综合评估与建议
[是否可用 / 需要优化 / 建议重新创作]
```

**执行步骤**：

## 六、 关键概念速查

| 概念 | 定义 |
|------|------|
| **超级符号工作法** | "寻找品类强相关文化母体 ➔ 私有化改造 ➔ 注入品牌记忆体" |
| **话语母体** | 大众熟知的话语句式、俗语、行为指令、经典旋律 |
| **品类强相关** | 母体让消费者5秒内自发联想品类，无解释成本 |
| **旋律母体** | 经典儿歌、民谣、流行歌曲，可改造为品牌旋律 |
| **卖点金字塔** | 6层台阶：顶层特权→热销实证→第三方背书→功能对比→技术特征→底层基础 |
| **各触点独立母体** | 口号/符号/包装可各自调用最适配的母体类型 |
