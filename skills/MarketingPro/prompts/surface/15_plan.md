# MarketingPro 子模块提示词：全案 (15_plan)

## 一、 模块核心定位与触发指令

- **触发指令**：`/dd-plan`（或经 `/dd` 自动路由至全案/整体方案范畴）
- **核心职能**：将"顶层设计→中层4P运行规划→浅层物料与执行落地"全部融会贯通，输出简单、独特、战略级、简单可复制的品牌营销全案，并**配套基于品类强相关文化母体的全套AI生图提示词库**。
- **Deep Research前置**：执行本模块前，必须先完成行业/竞品全景调研。

---

## 二、 超级符号工作法在全案中的核心地位

> **重要澄清**：超级符号是一种工作方法，而非全局单一元素的死板延展。

**工作方法本质**：**"寻找与品类/场景强相关的文化母体 ➔ 进行私有化角色化改造 ➔ 注入品牌记忆体"**

### 各触点独立调用最适配的母体

| 触点 | 可调用的母体类型 | 案例 |
|------|------------------|------|
| **口号** | 语言/句式/旋律母体 | 蜜雪冰城调用《甜蜜蜜》→"蜜雪冰城甜蜜蜜" |
| **符号** | 视觉/角色/具象母体 | 蜜雪冰城调用雪人→雪王IP |
| **包装** | 形态/容器/场景母体 | 零食店购物袋→兔头萌角色 |
| **命名** | 文字/俗语/熟词母体 | 品牌名借用品类熟语 |

> 📌 **严禁要求企业在所有触点强行使用同一个符号**，而是要求每个触点都必须应用"超级符号工作法"。

---

## 三、 文化母体选择的**第一铁律**：品类/场景强相关

> ⚠️ **核心原则**：文化母体必须与**"该品类的消费场景、产品形态、使用动作或文化渊源"天然强绑定**，让消费者在看到母体的第一秒，脑海中立刻自发完成"场景联想 ➔ 品类联想 ➔ 品牌承诺"。

| 品类 | 品类强相关文化母体 | 私有化改造 |
|------|-------------------|------------|
| 零食连锁 | 购物袋 | 兔头萌角色 |
| 冰淇淋 | 雪人 | 雪王IP |
| 国风茶饮 | 戏剧脸谱 | 品牌角色 |

---

## 四、 母体私有化中的**角色化改造路径**（高优先级）

> **不是母体本身必须是角色，而是私有化改造时最好"角色化/拟人化"**

**认知科学依据**：人类大脑对"人脸、角色表情与眼睛"的识别速度最快。

**角色化改造示例**：
```
购物袋（品类强相关场景物体）
        ↓
私有化改造：赋予五官、表情、性格
        ↓
兔头萌角色（保留母体原力+角色识别优势）
```

## 六、 全案标准交付模具

### 第1章：顶层战略与定位

```
1.1 使命界定（3要素）
    - 对谁：[目标客户/社会群体]
    - 做什么：[解决什么社会问题]
    - 凭什么：[企业独特能力]

1.2 选战场
    - 主战场：[进入什么局部市场]
    - 坚决不做：[负向清单]

1.3 定位三层定义
    - 使命定位 / 经营定位 / 业务定位
```

### 第2章：增长驱动方式与4P协同规划

```
2.1 增长主型判定
    - 主型：[产品驱动 / 推广驱动 / 渠道驱动]

2.2 4P整体协同方案
    - Product：核心承诺 + 文化母体方向
    - Price：价格策略 + 利润分配
    - Place：渠道模式 + 核心任务
    - Promotion：核心动作 + 服务重心
```

### 第3章：品牌资产与文化母体体系

```
3.1 品类与场景分析
    - 品类：[品类名称]
    - 消费场景：[场景描述]

3.2 文化母体锁定（品类强相关）
    - 核心文化母体类型：[场景物体/自然原力/传统文化/...]
    - 母体选择理由：[为什么这个母体让消费者5秒联想品类]
    - 私有化改造方向：[角色化改造]

3.3 各触点母体规划（独立调用最适配母体）
    - 口号：话语/句式/旋律母体
    - 符号：视觉/角色/具象母体
    - 包装：形态/容器/场景母体

3.4 超级符号（角色化IP）
    - 符号描述：[...]
    - 角色化设定：[五官/表情/性格]
    - 可复述性：[用一句话描述]

3.5 口号（话语母体私有化）
    - 主Slogan：[...]
    - 借用的句式母体：[...]
    - 卖点金字塔：[6层梳理]
```

### 第4章：落地物料执行规范与AI生图套件

```
4.1 包装规范（品类强相关文化母体+角色化）
    - 文化母体视觉占比：[X%以上]
    - 角色化要求：[必须保留角色特征]
    - 信息层级：[购买理由/功能代价/可信度]

4.2 海报与KV规范（文化母体视觉统治）
    - 视觉重心：[品类强相关文化母体角色占据最大面积]
    - 主口号：[话语母体]

4.3 AI生图提示词套件（品类强相关+角色化）
```

## 八、 关键概念速查

| 概念 | 定义 |
|------|------|
| **超级符号工作法** | "寻找品类强相关文化母体 ➔ 私有化角色化改造 ➔ 注入品牌记忆体" |
| **品类强相关** | 母体让消费者5秒内自发联想品类，无解释成本 |
| **角色化改造** | 将母体赋予五官、表情、性格，转化为品牌IP（高优先级） |
| **各触点独立母体** | 口号/符号/包装可各自调用最适配的母体类型 |
| **三大定力** | 业务精炼、品牌精炼（锁定母体）、套路精炼 |
