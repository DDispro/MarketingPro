# 02 战略 (Strategy)

## 指令
/dd-strategy

## 核心定义

**战略 = 选战场、选产品、选顾客、打法简单可复制**

## 核心理论

### 企业是社会器官
- 企业的本质是解决社会问题
- 企业是帮助社会将生产资料从效率低的地方搬到高的地方
- 使命是产品开发
- 产品是战略的唯一表达

### 战略是涌现的过程

**战略不是被创造出来的，是被发现出来的。**

战略制定过程示例（麻辣烫案例）：
1. 开麻辣烫铺 → 发现可以开两家 → 直营连锁战略
2. 干不过来 → 找人一起开 → 加盟连锁战略
3. 原料采购量大 → 自己产 → 整合供应链战略
4. 加工多了 → 卖给别人 → 预制菜战略
5. 5000家门店 + 行业拥趸 → 卖包装麻辣烫 → 零售发展战略

### 战略的胜出方式
- 总成本领先是波特的本质
- 波特五力：新品牌进入市场的壁垒

### 核心原则
- **先求不可败**
- **以约失之者，鲜矣** —— 大道至简

## 任何阶段的战略制定

### 核心观点
任何阶段的战略制定都是一样的。

### 正确做法
**扩大自己已经发展出来的最强、最快、最高的业务线，而不是臆想新战略。**

### 战略与创新

| 要素 | 说明 |
|------|------|
| 创新 | 战略的本质 |
| 产品 | 创新的表达 |
| 通过营销 | 卖出去 |

## 执行要点

- 选对战场比打法更重要
- 简单可复制是判断好战略的标准
- 战略定力：不分散核心资源
- 新战略需要观察和等待，不是创意
