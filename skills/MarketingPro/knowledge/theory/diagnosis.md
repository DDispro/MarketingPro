# 品牌营销诊断指南

## 诊断的核心逻辑

### 品牌=复购 诊断框架

**核心问题**：
1. 顾客是否接受品牌的承诺？
2. 顾客是否因为承诺而复购？
3. 品牌是否形成了"0成本的复购"？

### 诊断维度

| 维度 | 检查问题 |
|------|---------|
| 承诺清晰度 | 品牌承诺是什么？是否清晰具体？ |
| 承诺可信度 | 凭什么相信这个承诺？ |
| 承诺传递 | 前序体验是否有效传递承诺？ |
| 承诺兑现 | 产品/服务是否兑现承诺？ |
| 复购机制 | 顾客复购的原因是什么？ |
| 奖惩机制 | 品牌展现成本是否足够高？ |

---

## 增长方式诊断

### 第一步：判断增长类型

**问题1**：你的产品利润能支持顾客直接体验吗？
- 如果是 → **产品驱动型**

**问题2**：你的产品需要靠推广刺激即时购买吗？
- 如果是 → **推广驱动型**

**问题3**：你的顾客需要渠道引导才能做购买决策吗？
- 如果是 → **渠道驱动型**

### 增长方式匹配检查

#### 产品驱动型检查清单
- [ ] 产品是否足够优越？
- [ ] 体验渠道是否设计完善？
- [ ] 服务人员是否以服务为导向？
- [ ] 陈列是否体现高价值感？
- [ ] 价格是否支撑高端定位？

#### 推广驱动型检查清单
- [ ] 是否有足够的购买冲动设计？
- [ ] 是否有记忆度设计？
- [ ] 是否在抢占用户心智？
- [ ] 包装是否醒目易识别？
- [ ] 是否在优势渠道有足够排面？

#### 渠道驱动型检查清单
- [ ] 渠道是否愿意卖？
- [ ] 渠道是否知道怎么卖？
- [ ] 是否有统一的选择标准？
- [ ] 是否有行业背书或权威认证？
- [ ] 是否有培训和支持体系？

## 4P一致性诊断

### 核心问题
> 营销的4P是否匹配增长方式？

| 增长方式 | 4P应服务于 |
|---------|-----------|
| 产品驱动型 | 产品优越性 |
| 推广驱动型 | 购买必要性/即时性/冲动性 |
| 渠道驱动型 | 渠道意愿与认知统一 |

### 诊断问题

1. **Product**：产品设计是否匹配增长方式？
2. **Place**：渠道策略是否匹配增长方式？
3. **Promotion**：推广策略是否匹配增长方式？
4. **Price**：价格策略是否匹配增长方式和品牌定位？

## 品牌资产诊断

### 品牌资产3形态检查

| 资产形态 | 检查问题 |
|---------|---------|
| 名称 | 是否可描述、可记忆、有意义？ |
| 视觉资产 | 是否醒目、独特、可识别？ |
| 文本信息 | 是否精炼、可复述、与承诺一致？ |

### 品牌储蓄诊断

**问题**：品牌是否在持续储蓄？

| 检查点 | 是/否 |
|-------|------|
| 包装是否在传递核心品牌资产？ | |
| 每次营销活动是否在积累品牌资产？ | |
| 是否有被遗忘或丢失的品牌资产？ | |
| 是否在搞"品牌升级"而丢失原有资产？ | |

## 定力·定型·定投 诊断

### 战略定力检查
- [ ] 是否在核心业务上持续投入？
- [ ] 是否被"貌似有前景"的机会分散资源？
- [ ] 是否在审慎评估后才决定扩张？

### 资产定型检查
- [ ] 品牌资产是否从一开始就定型了？
- [ ] 是否在搞品牌升级？
- [ ] 品牌资产是否容易被记忆？
- [ ] 是否在持续储蓄同一个品牌记忆？

### 营销定投检查
- [ ] 是否有持续奏效的营销方式？
- [ ] 是否有可复制的打法？
- [ ] 是否在追逐"新营销"而浪费资源？
- [ ] 增长是否是提前设计的？
