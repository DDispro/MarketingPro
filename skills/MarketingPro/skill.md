## 核心方法论

### 品牌 = 复购

> **品牌 = 企业给自己设计的一个方便客户奖惩的标签**
> - 唯一目的：让消费者复购
> - 终极效果：取消销售（0成本的复购）
> - 作用机制：顾客奖惩

### 增长方式决定营销

| 增长类型 | 特征 | 4P应服务 |
|---------|------|---------|
| **产品驱动型** | 产品利润 > 顾客体验成本 | 产品优越性 |
| **推广驱动型** | 产品利润 < 顾客体验成本 | 购买冲动 |
| **渠道驱动型** | 顾客无法抹除信息差 | 渠道意愿 |

### 执行协议

```
Deep Research → 方法论漏斗 → 战略输出
```

无论调用哪个模块，系统都会先执行深度市场调研，再输入方法论漏斗分析，最后输出结构化成果物。

## 指令系统

### 总控指令（推荐）

| 指令 | 功能 |
|------|------|
| `/dd [业务描述]` | 总入口，自动识别需求，Deep Research + 方法论 + HTML报告 |
| `/dd-research [品类/品牌]` | 独立行业与竞品深度调研 |

### Deep层：品牌·战略·定位

| 指令 | 模块 | 说明 |
|------|------|------|
| `/dd-brand` | 品牌模块 | 承诺+记忆体、品牌三阶段、0成本复购路径 |
| `/dd-strategy` | 战略模块 | 社会器官论、产品机翼、选战场 |
| `/dd-positioning` | 定位模块 | 三层定位、降低交易成本、明确不做什么 |

### Middle层：增长·4P

| 指令 | 模块 | 说明 |
|------|------|------|
| `/dd-growth` | 增长方式 | 三大驱动分型、4P协同审查 |
| `/dd-product` | 产品规划 | 机翼模型、优越感/目的性体验 |
| `/dd-price` | 战略定价 | 利润分配机制、价格曲线 |
| `/dd-place` | 渠道策略 | 场景+人、终端生动化 |
| `/dd-promotion` | 推广战役 | 增长方式驱动的推广重心 |

### Surface层：物料·全案

| 指令 | 模块 | 说明 |
|------|------|------|
| `/dd-naming` | 命名设计 | 文字母体私有化、极低传播成本 |
| `/dd-symbol` | 品牌符号 | 视觉母体私有化、超级符号、AI生图 |
| `/dd-slogan` | 口号提炼 | 卖点金字塔6层、3秒购买理由 |
| `/dd-packaging` | 包装策划 | 包装3必要、文化母体货架统治 |
| `/dd-poster` | KV海报 | 母体视觉统治、终端陈列体验 |
| `/dd-csr` | CSR方案 | 零负担/促增长/可持续 |
| `/dd-plan` | 营销全案 | 顶层+中层+浅层融会贯通 |
