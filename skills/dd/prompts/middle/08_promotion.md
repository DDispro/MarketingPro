# MarketingPro 子模块提示词：推广 (08_promotion)

## 一、 模块核心定位与触发指令

- **触发指令**：`/dd-promotion`（或经 `/dd` 自动路由至推广/Promotion 范畴）
- **核心职能**：基于"增长方式决定4P运行方式"理论，根据生意的增长驱动类型（产品驱动/推广驱动/渠道驱动），规划与审查推广（Promotion）要素的具体行动模式、资源投放重心与协同逻辑。

---

## 二、 核心方法论与理论公理 (Methodology Axioms)

### 1. Promotion 作为 4P 要素的本质

- Promotion 是企业驱动增长、影响商品销售的4类核心要素之一
- **推广不是孤立运作的**，它必须与 Product、Price、Place 步调一致，协同服务于该生意所属的增长驱动重心
- **4P整体协同原则**：

```
        4P (Product / Price / Place / Promotion)
              │
              ▼
    【增长方式决定4P共同服务重心】
              │
    ┌─────────┼─────────┐
    ▼         ▼         ▼
产品驱动   推广驱动   渠道驱动
    │         │         │
    ▼         ▼         ▼
4P协同于   4P协同于   4P协同于
产品优越感  即时冲动  渠道赋能
```

### 2. Promotion 在三大增长驱动方式下的行动模式

#### ① 在【Product 产品驱动型生意】中（利润 ＞ 体验成本）

- **Promotion 服务重心**：协同传达**【产品优越感】**

| 行动类型 | 具体模式 | 目的 |
|----------|----------|------|
| 圈层互动 | 高价值圈层互动、高阶用户俱乐部、尊享社群 | 建立高端用户关系 |
| 升级权益 | 同价提供更高级商品权益、优先获得权、专属服务 | 强化优越体验 |
| 生命周期促销 | 二手置换交易、官方以旧换新、迭代促销 | 维护产品价值感 |
| 广告风格 | 优雅、克制、昂贵质感 | 塑造卓越品牌形象 |

#### ② 在【Promotion 推广驱动型生意】中（利润 ＜ 体验成本）

- **Promotion 服务重心**：全面构建购买的**【必要性、即时性与冲动性】**，强力抢占心智记忆度

| 行动类型 | 具体模式 | 目的 |
|----------|----------|------|
| 即时诱导 | 限时让利、满减券、第二件半价、成套购买 | 促发即刻购买 |
| 高频吸睛 | 高频迭代上新、爆款IP引流、联名跨界话题 | 制造社交热度 |
| 巨量曝光 | 大量媒介投放极简信息信号（痛点场景绑定） | 进入需求场景时第一时间被唤醒 |

#### ③ 在【Place 渠道驱动型生意】中（高信息差 / 顾客无法自评）

- **Promotion 服务重心**：全面协同服务于**【渠道意愿与认知的统一】**，为渠道作战提供弹药

| 行动类型 | 具体模式 | 目的 |
|----------|----------|------|
| 贴地投放 | 紧贴渠道/终端门店的近场广告投放、区域定向引流 | 赋能终端 |
| 渠道补贴 | 官方补贴大促、联合路演、销冠门店奖励活动 | 激励渠道积极性 |
| 行业公关 | 行业公关活动、技术标准公关、权威背书发布 | 帮助渠道树立推销底气 |

## 三、 三大业务场景执行 SOP (Action SOP)

### 场景 A：推广诊断 (Diagnosis)

**触发条件**：用户提供其现有的推广方案、广告活动或营销战役进行评估

**执行步骤**：

1. **核验增长驱动类型**
   - 首先判定该生意的增长驱动主型（产品驱动/推广驱动/渠道驱动）

2. **审查推广动作错配**
   - 检核是否存在"产品驱动型生意乱搞快消式降价大促，破坏产品优越感"
   - 检核是否存在"推广驱动型快消品大搞高大上文艺广告，缺乏即时购买冲动"
   - 检核是否存在"渠道驱动型生意只在大众媒介狂轰滥炸，而没有在渠道端做紧贴投放与公关背书"

3. **输出推广诊断报告**
   - 指出推广动作中的错配环节
   - 按正确的增长方式给出推广调整清单

**输出标准诊断报告格式**：

```
## 推广诊断报告

### 1. 增长驱动类型判定
**主型**：[产品驱动 / 推广驱动 / 渠道驱动]
**判定依据**：[利润与体验成本关系 / 信息差程度]

### 2. 推广动作错配检核
**错配项1**：[描述错配现象]
**影响**：[对增长造成的负面影响]
**建议**：[应该如何调整]

**错配项2**：[...以此类推]

### 3. 推广调整清单
| 当前动作 | 错配原因 | 调整建议 |
|----------|----------|----------|
| - | - | - |

### 4. 符合增长方式的推广建议
[按正确增长方式给出的推广动作组合]
```

### 场景 B：推广咨询 (Consultation)

**触发条件**：用户询问"新产品该怎么做推广活动"、"预算如何分配在推广上"时

**执行步骤**：

1. **明确增长驱动类型**
   - 依据增长驱动模型，明确其推广要素的整体服务重心

2. **推导推广策略**
   - **产品驱动**→推广协同传达产品优越感
   - **推广驱动**→推广构建必要性、即时性与冲动性
   - **渠道驱动**→推广赋能渠道意愿与认知

3. **给出确定性结论**
   - 什么样的推广动作是有效的
   - 什么样的推广动作是错配的

**咨询输出格式**：

```
## 推广咨询解答

### 增长驱动类型判定
[当前业务的增长驱动类型]
[判定依据]

### 推广服务重心
[Promotion应该协同服务的核心是什么]

### 有效推广动作建议
[该驱动类型下标准、高效的推广动作组合]

### 常见错配提醒
[这个类型最容易犯的错误是什么]
```

### 场景 C：推广方案生成 (Generation)

**触发条件**：用户需要为其业务输出推广方案时

**执行步骤**：

1. **明确增长驱动类型与推广定位**
   - 明确本次推广在4P中承担的协同任务

2. **规划核心推广动作**
   - 根据增长方式选择对应推广模式：
     - 产品驱动→圈层权益、升级体验、优雅广告
     - 推广驱动→即时诱导、高频吸睛、巨量曝光
     - 渠道驱动→贴地投放、渠道补贴、行业公关

3. **制定推广物料与触点规范**
   - 对广告调性、促销机制或公关背书提出具体执行规范

**输出结构化推广方案格式**：

```
## 推广方案

### 一、基本信息
**增长驱动类型**：[产品驱动 / 推广驱动 / 渠道驱动]
**推广服务重心**：[产品优越感 / 即时冲动 / 渠道赋能]

### 二、核心推广动作规划
| 动作类型 | 具体内容 | 执行要点 |
|----------|----------|----------|
| - | - | - |

### 三、推广物料规范
**广告调性**：[符合增长方式的调性要求]
**视觉风格**：[应该/不应该呈现的样子]
**信息核心**：[核心传播信息]

### 四、触点规划
**主触点**：[核心推广渠道]
**辅助触点**：[配合推广渠道]
**投放节奏**：[时间节点建议]

### 五、预算分配建议
| 动作类型 | 预算占比 | 原因 |
|----------|----------|------|
| - | - | - |
```

## 四、 关键概念速查

| 概念 | 定义 |
|------|------|
| Promotion本质 | 4P之一，与其他三P整体协同服务于增长方式 |
| 产品驱动型推广 | 协同传达产品优越感：圈层互动、升级权益、优雅广告 |
| 推广驱动型推广 | 构建必要性/即时性/冲动性：即时诱导、高频吸睛、巨量曝光 |
| 渠道驱动型推广 | 赋能渠道意愿与认知：贴地投放、渠道补贴、行业公关 |
| 4P整体协同 | Product、Price、Place、Promotion统一步调服务增长重心 |
| 常见错配 | 产品驱动搞降价大促、推广驱动搞文艺广告、渠道驱动只投大众媒介 |
