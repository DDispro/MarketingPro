## 核心方法论

### 超级符号工作法在全案中的核心地位

> **工作方法本质**："寻找与品类/场景强相关的文化母体 → 进行私有化角色化改造 → 注入品牌记忆体"

| 触点 | 可调用的母体类型 | 案例 |
|------|------------------|------|
| **口号** | 语言/句式/旋律母体 | 蜜雪冰城调用《甜蜜蜜》→"蜜雪冰城甜蜜蜜" |
| **符号** | 视觉/角色/具象母体 | 蜜雪冰城调用雪人→雪王IP |
| **包装** | 形态/容器/场景母体 | 零食店购物袋→兔头萌角色 |

### 文化母体选择的第一铁律：品类/场景强相关

> **核心原则**：文化母体必须与**"该品类的消费场景、产品形态、使用动作或文化渊源"天然强绑定**。

| 品类 | 品类强相关文化母体 | 私有化改造 |
|------|-------------------|------------|
| 零食连锁 | 购物袋 | 兔头萌角色 |
| 冰淇淋 | 雪人 | 雪王IP |
| 国风茶饮 | 戏剧脸谱 | 品牌角色 |

### 全案交付框架

#### 第1章：顶层战略与定位
```
1.1 使命界定（3要素）
    - 对谁：[目标客户/社会群体]
    - 做什么：[解决什么社会问题]
    - 凭什么：[企业独特能力]

1.2 选战场
    - 主战场：[进入什么局部市场]
    - 坚决不做：[负向清单]

1.3 定位三层定义
    - 使命定位 / 经营定位 / 业务定位
```

#### 第2章：增长驱动方式与4P协同规划
```
2.1 增长主型判定
    - 主型：[产品驱动 / 推广驱动 / 渠道驱动]

2.2 4P整体协同方案
    - Product：核心承诺 + 文化母体方向
    - Price：价格策略 + 利润分配
    - Place：渠道模式 + 核心任务
    - Promotion：核心动作 + 服务重心
```

#### 第3章：品牌资产与文化母体体系
```
3.1 品类与场景分析
    - 品类：[品类名称]
    - 消费场景：[场景描述]

3.2 文化母体锁定（品类强相关）
    - 核心文化母体类型：[场景物体/自然原力/传统文化/...]
    - 母体选择理由：[为什么这个母体让消费者5秒联想品类]

3.3 各触点母体规划（独立调用最适配母体）
    - 口号：话语/句式/旋律母体
    - 符号：视觉/角色/具象母体
    - 包装：形态/容器/场景母体
```

## 执行协议
