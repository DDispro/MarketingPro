# 战略与定位

## 战略基本定义

### 企业两大基本职能
1. **创新** - 发想新产品，创造新市场
2. **营销** - 将产品卖出去，创造新顾客

> 两者相加，就基本上形成了企业战略。

### 战略的本质 —— 确定战场！

> 孙子兵法：势者，因利而制权也。

**战场决定**：
- 你面对的敌人
- 你将获得的胜果
- 你将采取的打法
- 你需要投入的资源

**为什么必须选战场？**
- 我们不可能拥有无限资源
- 不可能面对太多种类对手
- 不可能一次性打赢所有战场

### 正确战场的标准：拥有局部优势

| 市场情况 | 机会点 |
|---------|-------|
| 市场都卖高端 | 性价比有机会 |
| 市场高中低都有 | 针对特色人群有机会 |
| 特色挑花眼了 | 回归基础款有机会 |
| 大家都便宜了 | 整合供应链有机会 |
| 大家都供应链了 | 抓渠道资源有机会 |
| 渠道已经饱和 | 附加价值有机会 |

## 战略的完整内容

### 战略盘点
| 维度 | 内容 |
|------|------|
| 能力 | 你能做什么 |
| 优势 | 你的独特做法能在这个局部形成相对优势 |
| 空间 | 这个优势确实是市场需要的存在空间 |

### 战略确定
| 维度 | 内容 |
|------|------|
| 产品 | 充分利用了局部优势的产品或产品组合 |
| 顾客 | 针对什么顾客或针对顾客什么特征 |
| 资源 | 有足以覆盖局部的资源和可持续回报 |

### 战略计划
- 一个从推出到营销到售出的完整销售套路
- **简单可复制**：简单则成本低，可复制则可扩大

---

## 战略计划框架

```
市场空间 ←—— 企业能力 + 独特优势
     ↓
  产品组合 + 进攻市场 + 目标客户
     ↓
 可复制打法（复制计划/推进表）
```

### 战略条件
- 能做什么（企业能力）
- 会做什么（独特优势）
- 战略门槛：别人不行就你行

### 战略表达
- 针对性产品

### 战略目标
- 营销：怎么推向市场
- 对谁发声

### 战略打法
- 销售逻辑

---

## 定战略的重点

### 战略重点是舍弃
- 为了集中力量获得有市场潜力的某种特定优势
- 你将不再满足其他某些市场需求

### 打法的重点是简单
- 由于你拥有特定优势且满足了需求
- 因此你将拥有轻松拿下客户的特定打法
- **如果不轻松说明战略错了**

### 赢的方式是复制
- 你将舍弃其他打法而集中资源投入复制特定打法
- **如果打法不可复制说明打法错了**

## 两种定位

### 1. 心智定位（品牌识别）
> 目前主流思想中心智定位的含义为"树立细分市场顾客第一心智"。看起来好像没错但实际上根本没用。

**关键洞察**：
- 品牌是营销的成果，而不是你定好位了品牌就成立了
- 心智是成果，而不是达成目的的方法
- 王老吉成为凉茶品类第一心智，这是**成果**
- 不是说专注凉茶品类的定位帮助了王老吉成为第一

### 2. 战略定位（业务、经营、使命）

**核心本质是一个自梳理**：
- 从思想统一到行为统一
- 内部获得经营与管理的降本增效
- 外部获得品牌认知的降本增效

## 企业战略的简单定义

> 企业战略就是企业计划用什么产品创造什么顾客！

### 基于这个定义
| 概念 | 说明 |
|------|------|
| 产品 | 战略的唯一表达 |
| 产品组合 | 战略模型的具体化 |
| 顾客和顾客所在市场 | 战略目标 |
| 创新 | 战略的唯一方式 |
| 新战略 | 企业在定义自己未来的产品线 = 新产品 + 新顾客 + 匹配的营销打法 |

---

## 定位的目的 —— 降低内外交易成本

### 三层定位

| 定位类型 | 作用 |
|---------|------|
| 使命定位 | 让内外部明确知道你是干什么的 |
| 经营定位 | 让内部知道我们打算怎么做生意 |
| 业务定位 | 内部产品共识，外部知道如何消费你 |

### 降低交易成本的意义
通过明确战略定位，实现：
- 产品与业务的固化
- 统一内外部知识信息及流程
- 减少企业或业务或营销或经营的新增项干扰项
- 降低管理成本、教育学习成本、认知统一成本
- 使得企业能力便于迭代生长

**即**：易于管理，易于竞争，易于改善

## 定位的最核心意义

> **不是明确要做什么，而是明确不做什么**

因为只有不做某些要素，才能降本增效。

| 定位类型 | 明确"不做什么" |
|---------|---------------|
| 使命定位 | 不提倡什么文化 |
| 经营定位 | 不做哪些生产与营销 |
| 业务定位 | 不售卖哪些产品 |
