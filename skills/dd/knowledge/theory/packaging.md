# 包装 Packaging

## 核心观点

> **包装是重大营销，甚至常常处于第1位**

### 为什么包装如此重要？

| 特性 | 说明 |
|------|------|
| 对产品的预介绍 | 顾客在购买前首先看到的是包装 |
| 重要的顾客购买的前序体验 | 包装是顾客体验品牌承诺的第一步 |
| 企业完全主控的营销部分 | 不受渠道、媒体限制 |
| 极低成本的营销部分 | 一次印刷，长期展示 |
| 售卖前最直接的产品说服 | 唯一在购买瞬间发挥作用的营销物料 |

**总结**：便宜、可控、重要

---

## 不同生意的包装形式

| 生意类型 | 包装形式 |
|---------|---------|
| 常规货架销售商品 | 包装 = 产品包裹面 |
| 餐饮零售 | 包装 = 门面设计 |
| 大宗交易物/昂贵交易物 | 包装 = 门店体验空间 + 产品手册 + 服务人员 |
| B2B生意 | 包装 = 官网 + 公司简介 + 产品手册 + 自媒体空间 |
| 电商生意 | 包装 = 详情页 |

---

## 包装的3必要

无论包装形式怎么变化，包装中都有3个必要要素：

### 1. 购买理由
- 顾客为什么要买我？
- 我的差异化价值是什么？

### 2. 功能（代价）
- 什么用处？用处多大？
- 支付多少？谁消费？

### 3. 可信
- 信任理由是什么？
- 凭什么相信我说的？

---

## 包装检查清单

- [ ] 购买理由是否清晰呈现？
- [ ] 功能价值是否具体可感知？
- [ ] 信任理由是否足够？
- [ ] 是否符合增长方式（产品驱动/推广驱动/渠道驱动）？

---

## 包装是心智的储蓄罐

### 核心理念
- 包装是重大的营销
- 营销应该形成品牌资产
- 包装在形成品牌资产中扮演重大角色

### 最佳实践

#### 1. 将资产放在包装的最中心
- 核心品牌资产必须在包装上占据最显眼位置
- 顾客第一眼就能看到

#### 2. 将资产放在包装的多处
- 多处重复，强化记忆
- 不同角度都能看到品牌资产

---

## 可被复述的包装

**最好的包装是可被复述的包装**

| 资产类型 | 说明 |
|---------|------|
| 可被复述的LOGO | 能准确描述给别人听 |
| 可被复述的主张口号 | 简单易记的一句话 |
| 可被复述的包装造型 | 独特到可以描述 |
| 可被复述的重点品牌资产 | 让人记住并传播 |

---

## 品牌资产三形态与包装

| 资产形态 | 效率 | 在包装上的体现 |
|---------|------|--------------|
| 名称 | 完全统治 | 必须突出 |
| 视觉资产 | 中等 | 醒目呈现 |
| 文本信息 | 效率最高 | 必须可描述可复述 |

---

## 包装效果对比

| 类型 | 表现 |
|------|------|
| 最好的包装 | 顾客没购买都完成了一次体验 |
| 最差的包装 | 顾客买完了体验完了却忘了或甚至不知道你是什么品牌 |
