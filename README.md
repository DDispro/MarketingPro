**MarketingPro**

基于第一性原理与商业底层规律的顶级品牌战略与全案营销 AI 智能体，致力于将企业在心智黑暗森林中的购买坐标转化为零成本复购的商业发动机。

**项目出发点与初心**

能指导实践的才是真正的理论。本项目希望将真正的科学闭环营销带给大家，旨在将这套严密闭环的顶级咨询方法论，封装为任何智能体（Agent）都能即插即用的通用能力体系。

**使用方法**

安装完成后，你可以直接在聊天框中与 MarketingPro 协作，支持以下两种调用方式：

**方式 1：总指令极速调用（推荐）**

直接输入总控指令 /dd 并跟上业务背景或需求，系统会自动识别所属范畴、启动全网深度市场调研（Deep Research），并直接交付包含策略、文案与生图方案的完整报告。
- 对话示例：/dd 我想做一个高端即饮无糖茶品牌，客单价 8-12 元，帮我输出一份包含 4P 规划、品牌设计和主打口号的完整全案。
- 对话示例：/dd 我们是一家做工业智能检测设备的公司，请帮我诊断我们目前的渠道策略与价格体系是否存在错配。

**方式 2：精准分支指令调用（专项定向输出）**

如果有明确的单项交付需求，可直接输入对应分支指令：
- 做包装：/dd-packaging 我们是一款面向年轻白领的熬夜滋补饮品，请输出包装正面层级策划与 3D 渲染图生图 Prompt。
- 设计品牌符号：/dd-symbol 我们是一家主打少油少盐的社区轻食连锁店，请帮我寻找强关联的文化母体，并输出角色化 IP 改造方案与生图词。
- 提炼品牌口号：/dd-slogan 基于卖点金字塔，为我们的便携式咖啡机提炼 3 条 3 秒能说完、包含具体事实的主打 Slogan。
- 查行业竞品：/dd-research 帮我深度调研当前国内精酿啤酒赛道的主流价格带、头部品牌包装视觉形态与共性认知盲区。

**交付成果**

- 市场深度洞察：自动检索行业现状与竞品包装及卖点盲区。
- 第一性原理战略策略：基于增长驱动分型（产品/推广/渠道驱动）的 4P 一致性规划。
- 视觉与物料交付：品牌资产设计，以及可直接用于生图的 Prompt 模具。
- 独立交互式 HTML 成果物：结构清晰、卡片化排版、内嵌视觉物料的单文件报告，支持浏览器查阅或转为 PDF 汇报。

**核心优势与特色**

- 全局 Deep Research 事实漏斗：在生成策略前强制执行市场深度调研，扫描行业现状、竞品陈列、包装形态与主流价格带，拒绝理论空想。
- 三大增长驱动型 4P 动力学：精准判定生意驱动方式。产品驱动型（利润大于体验成本）聚焦产品优越性；推广驱动型（利润小于体验成本）聚焦购买必要性与冲动性；渠道驱动型（高信息差/无法自评）聚焦渠道意愿与认知建设。
- 品牌资产设计引入超级符号理论体系：赋能全案物料。向华杉老师致敬。
- 通用 AI 生图引擎：内置标准化图像生成指令模具，支持跨平台自动生图或输出高质量中英双语 Prompt。
- 独立交互式 HTML 交付物：支持生成卡片化排版、内嵌图片的单文件 HTML 报告，方便直接预览与导出 PDF。

**指令系统全览**

- /dd：总控中枢，智能识别需求，前置 Deep Research，全盘推导并输出战略与 HTML 报告。
- /dd-research：深度调研，指定品类/竞品的市场现状、物料形态与盲区深度扫描报告。
- /dd-brand：品牌本质，品牌奖惩标签设计、记忆体与承诺构建、0成本复购路径。
- /dd-strategy：企业战略，使命界定、选战场、产品机翼精简、总成本领先设计。
- /dd-positioning：战略定位，使命/经营/业务三层定位梳理，明确“不做什么”以降低内外交易成本。
- /dd-growth：增长方式，产品/推广/渠道驱动三大分型诊断与 4P 协同一致性审查。
- /dd-product：产品规划，战略表达载体、产品机翼设计、优越性/目的性体验规划。
- /dd-price：战略定价，利润分配驱动机制设计（研发端/顾客端/渠道端）。
- /dd-place：渠道策略，销售场景与人、第一波顾客武装、终端生动化。
- /dd-promotion：推广战役，基于增长方式的推广重心配置（圈层权益/即时大促/近场公关）。
- /dd-naming：专属命名，专属指代方式、统帅具体物与描述、极低呼叫成本命名。
- /dd-symbol：品牌符号，场景关联文化母体挖掘、角色化私有化改造、AI 生图 Prompt。
- /dd-slogan：口号卖点，卖点金字塔 6 层台阶结构、3秒极简购买理由提炼。
- /dd-packaging：包装策划，包装 3 必要（购买理由/功能代价/可信度）策划、3D 渲染图生议案。
- /dd-poster：主视觉KV，终端海报规划、信息极简呈现、商业广告摄影生图 Prompt。
- /dd-csr：正确CSR，溢出产能利用、零负担/促增长/可持续的社会责任方案。
- /dd-plan：营销全案，战略到落地的完整品牌营销战斗手册（含生图套件与独立 HTML 案）。
