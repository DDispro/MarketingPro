# MarketingPro

> 品牌营销第一性原理方法论智能体 SKILL

---

## 🎯 简介

**MarketingPro** 是一个基于"品牌=复购"理论的品牌营销方法论智能体 SKILL。它将 DD 的品牌营销方法论产品化，为品牌营销从业者提供：

- 🔍 **品牌诊断** - 输出标准化诊断报告
- 💬 **咨询问答** - 提供专业方法论答案
- ✍️ **物料生成** - 生成 slogan、文案、海报、详情页等
- 📋 **战略制定** - 制定完整的品牌战略全案

---

## 💡 核心方法论

### 品牌 = 复购

> 品牌的唯一目的是让消费者复购，终极效果是 **0成本复购 = 取消销售**

### 三种增长方式

| 类型 | 特征 | 4P服务重心 |
|------|------|-----------|
| 产品驱动型 | 产品利润 > 顾客体验成本 | 产品优越性 |
| 推广驱动型 | 产品利润 < 顾客体验成本 | 购买冲动 |
| 渠道驱动型 | 顾客无法抹除信息差 | 渠道意愿 |
